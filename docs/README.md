# 文档索引

战地图章工具项目的文档，按「类型」分目录组织。当前项目包含**图章离线渲染器**组件，
并预研**学习式徽章生成模型**。

## 目录约定

| 目录 | 类型 | 收什么 |
|------|------|--------|
| `renderer/` | 组件规格 | 已落地、随代码演进的技术规格（与代码同生命周期） |
| `research/`  | 预研 / 设计 | 未落地的探索、调研、目标架构设计（前瞻性，允许超前于代码） |

> 区分原则：**renderer/ 描述「现在是什么样」，research/ 描述「打算做成什么样」**。
> 一篇 research 设计落地为代码后，应在 renderer/（或未来的对应组件目录）补一份「现状规格」，
> 两者并存——前者记决策动机，后者记当前行为。

## renderer/ — 组件规格

- [徽章离线渲染器](renderer/emblem-renderer.md) — 编辑器导出 JSON → PNG 的数字孪生：
  JSON 格式、渲染管线、SVG 光栅化、图章库、配置、CLI。

## research/ — 预研 / 设计

- [通用图章生成模型调研](research/generative-model-survey.md) — Transformer/RL 生成式
  图章模型的概念综述：白盒程序输出、图层剥离、预算嵌入、宏观规划（愿景层）。
- [徽章生成模型设计（RL 闭环）](research/emblem-rl-model.md) — 落地工程方案：MDP 形式化、
  可微环境、模型架构、四阶段训练飞轮（自监督预训练→数据引擎→蒸馏→GRPO）、评测与风险。
  **当前的主攻方向。**

## 未来可能的分类（预留）

随项目演进，如出现新类型文档，在 `docs/` 下新建对应目录并登记到本表，例如：

- `environment/` — 可微渲染器 / RL 环境实现后的规格（现属 research 的 §2，落地后迁出）。
- `data/` — 数据引擎语料、标注、质量控制规范。
- `evaluation/` — 评测基准、人评流程、基线对比报告。
- `decisions/` — 关键架构决策记录（ADR）。
