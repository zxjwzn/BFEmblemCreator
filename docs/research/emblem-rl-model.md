# 徽章生成模型设计：自监督预训练 + 专家蒸馏 + GRPO 强化学习闭环

> 把 `generative-model-survey.md`（下称「调研」）的愿景落成可执行的工程方案。
> 任务：**输入一张图像，输出一段 ≤40 层的图章程序（徽章 JSON）**，使其离线渲染结果在
> 「语义神似 + 结构贴合」上逼近目标。这是 **image→program 的白盒生成**，不是像素扩散。

---

## 0. 定位与诚实前提

### 0.1 为什么难（先承认墙在哪）

调研 §一 的几何-GPT 案例能成立，是因为它有「把真实图逆向拆成几百步连续图元」的
**现成拟合算法**当数据工厂。本项目**没有**这个前提，且更难：

| 维度 | 几何-GPT 案例 | 本项目 |
|------|---------------|--------|
| 图元 | 连续可微的矩形/椭圆 | **256 个离散异形图章**（火焰/翅膀/文字…） |
| 序列长度 | 数百步 | **≤40 层**（极低预算） |
| 逆向数据源 | 现成（Primitive/Geometrize） | **不存在，要自己造** |
| 损失 | 像素 MSE 即可 | 必须**语义/感知**，否则预算被背景吃光 |

**结论：「逆向拟合」这一步在本项目里不是免费数据源，而是第一座要攻的山。**
因此通往 RL（调研的「极致形态」）的唯一可行路径，是先老老实实穿过提议器/蒸馏（A/B）。

### 0.2 经典拟合路线的失效模式（为什么转向学习）

「贪心选层 + 梯度直接优化合成图」这类经典路线有四个结构性失效根因，正是学习要补的能力：

1. **贪心不可逆**：首步选错基底轮廓，后续所有层都在补救错误骨架，无回溯/重启。
2. **无资产替换**：只调连续参数、从不换图章——离散选择一旦错就锁死。
3. **缺宏观规划**：没有「预算还剩多少、该抓大还是放小」的全局观，逐层短视。
4. **像素/边缘损失 ≠ 神似**：loss 在降、人眼看不像（缺语义感知项）。

这些正是调研 §四 点名的「局部贪心 / 无前瞻」缺陷，必须用**学习 + 闭环奖励**来补。

### 0.3 全局约束

- 单卡 RTX 级消费 GPU；可训练参数控制在 ~50M 量级；编码器冻结。
- 图章库固定 256；画布 320×320；输出即编辑器 JSON（底层在前）。
- **训练内环的 GPU 可微渲染器为待建组件（§2）**；PIL 渲染器只做评测/导出。

## 1. 问题形式化（MDP）

把「叠图章」建模为有限视界序列决策（调研 §三.2 的 SPIRAL 路线）：

- **状态** `s_t = (E_target, E_canvas_t, b_t)`：目标图特征、当前画布合成特征、剩余预算 `b_t = 40 − t`。
- **动作** `a_t = (asset, x, y, w, h, θ, flipX, flipY, color)`，外加 `STOP`。
  `asset ∈ {0..255}` 离散；其余连续（或量化 bin）——**混合离散-连续、变长**动作空间。
- **转移** `canvas_{t+1} = composite(canvas_t, render(a_t))`：确定性，由环境（§2 渲染器）完成。
- **奖励** 以终局感知相似度为主：`r_T = R(target, canvas_T)`；可选稠密 shaping（§5.3）。`γ=1`，`T≤40`。

**三个结构性难点**（决定算法选型）：

1. `asset` 离散 ⇒ **不能端到端反传**，必须用策略梯度 / 搜索，而非纯可微优化。
2. 层间遮挡 ⇒ **credit assignment 难**：底层贡献被上层盖住，稀疏终局奖励难以归因到单步。
3. 奖励稀疏 ⇒ 冷启动随机策略几乎拿不到信号 ⇒ **必须先用监督把策略「扶上马」**（阶段 0–2）。

## 2. 环境：可微图章渲染器（**待建**）

RL 的 simulator、蒸馏的专家执行器、测试期搜索的评估器，都依赖一个 **GPU 批量、可微（至少梯度可用）** 的图章合成器。`grid_sample` 硬 alpha 即可提供足够梯度（无需软 alpha）。

**接口规格：**

```
render_stamp_batch(asset_id[B], affine[B,2,3], color[B,3], out_hw) -> rgba[B,4,H,W]   # 单层批量
composite_stack(layers[L]) -> rgba[4,H,W]                                              # 按序 alpha-over
similarity(target, canvas) -> scalar                                                   # 感知/结构复合分
```

- 用 `affine_grid + grid_sample` 做缩放/旋转/平移，硬 alpha 阈值 + 直通估计供给梯度。
- 速度目标：单层 <1ms（批量），40 层全合成 <10ms——RL rollout 是吞吐瓶颈。
- **与 PIL 渲染器职责分离**：可微版服务训练内环；PIL 版（`render.py`）做最终高保真导出与**离线评测仲裁**（避免「训练用 A 渲染、交付用 B 渲染」的口径漂移——评测一律以 PIL 版为准）。

## 3. 模型架构

调研 §四.1 的具体化。总可训练参数 ~50M，编码器冻结。

```
目标图 ──► [冻结视觉编码器] ─► target tokens (N×d_v) + global ─┐
                                                              ├─ cross-attn ─► [自回归程序解码器] ─► 动作头
当前画布 ─► [轻量 CNN] ──────► canvas tokens (M×d_v) ─────────┤        ▲            (asset/pose/color/stop)
                                                              │        │
图章库 256 ─► [形状描述子 ⊕ 渲染 embedding] = 记忆库 K/V ───────┘        │
预算 b_t ──► budget embedding (FiLM/AdaLN 注入每一步) ──────────────────┘
```

### 3.1 视觉编码器（冻结）
- **DINOv2-ViT-S/14 或 CLIP-ViT-B/16**，提 patch tokens + global。冻结以省算力、防小数据过拟合。
- DINOv2 的结构/边界特征对「贴合轮廓」更友好；CLIP 的语义特征对「神似」更友好——可两路拼接。

### 3.2 图章记忆库（Decal Memory Bank）
- 每个图章一个 key：**形状描述子**（SDF 矩 / Hu 矩 / 轮廓 Fourier 描述子，几何指纹）⊕ **渲染后过同一编码器的视觉 embedding**（语义指纹）。
- 离线预计算成 `256 × d_k`，作为解码器 cross-attention 的 K/V，用 **pointer / attention 打分**选 asset。
- 好处：新增图章只需补一行 embedding，不必重训分类头。

### 3.3 自回归程序解码器
- 6–8 层 Transformer decoder，`d_model=512`，因果 self-attn（已生成动作）+ 两路 cross-attn（目标、画布）+ 一路 cross-attn（记忆库）。
- 每步输出分解动作头：
  - **stop/asset 头**：一个 `STOP` logit + 对记忆库 256 路 attention logits。
  - **pose 头**：`(x, y, log w, log h, θ)`。推荐**量化 bin 的 categorical**（位置/尺寸 64 bin、角度 72 档=5°），比连续高斯更稳、与 RL/采样天然兼容；后期可改粗到细两级。
  - **flip 头**：2 bit 独立 Bernoulli。
  - **color 头**：先用固定调色板 categorical（K≈64 色）；保留 RGB 回归头作细化。

### 3.4 预算条件化（调研 §五.2 核心机制）
- 把归一化剩余预算 `b_t/40` 编成 embedding，**注入每一步**（FiLM 或 AdaLN 调制）。
- 作用：给模型「全局进度条」，使其在预算充足时堆细节、告急时收敛勾勒核心特征。
- **诚实前提**（调研 §五.2 警告）：这种规划能力必须在训练期真实体验「预算耗尽的惩罚」才能内化，
  即预算 token 只在 **SFT/RL 阶段**真正生效，纯预训练里它只是装饰。

### 3.5 人机协作与视觉意图跟随（调研 §一.1）

- 架构天然支持「可暂停、可编辑、可续写」：解码器以**当前画布**为条件——人类在编辑器里改完几层后，
  把改动后的画布重新编码喂回，模型即从新状态续写，而非从头重新生成。
- 输出是 JSON 程序 ⇒ **100% 精确编辑**、与人类作品无损互通（相对扩散模型的根本优势）。
- **训练**：在专家轨迹上做「截断 + 扰动」增强——随机截断序列并修改某个中间层（换色/换章/移位），
  让模型学会顺着被人类改过的视觉上下文继续，而非收敛回记忆模板（调研 §一.1 的「视觉接龙」）。
- **评测**：人改后「续写」的连贯性与目标一致率，列入 §6 人评项。

## 4. 训练路线（四阶段，破数据墙）

```
阶段0  自监督逆合成预训练   (免费标签, 教会"读懂徽章")
阶段1  数据引擎 = 改进的经典搜索 (昂贵专家数据, 决定上限)
阶段2  行为克隆 / 蒸馏       (把专家搬进网络, DAgger 纠偏)
阶段3  GRPO 强化学习微调     (真正的闭环, 超越专家)
        测试期搜索 ──expert iteration──► 反哺阶段1数据
```

### 阶段 0 · 自监督逆合成预训练（关键破局点）
- **数据**：用渲染器随机叠 `k∈[1,40]` 个图章（随机 asset/pose/color/背景）→ 合成图 `I`，**精确程序 `P` 免费可得**。无限生成。
- **任务 A（正向自回归）**：给 `I` 预测 `P`（image→program 自编码）。
- **任务 B（图层剥离课程，调研 §五.1）**：给前 `t` 层合成图 `I_t`，预测并剥离第 `t` 层 → 逆向循环，等价于把 `P` 倒序训练。利用「最上层图元永远完整裸露」的无歧义性，教会遮挡语法。
- **真实徽章混入（可选）**：若能收集玩家制作的徽章 JSON，按倒序剥离混入课程（调研 §五.1 的原始形态），作为合成分布之外的「真实锚点」。
- **域随机化**：颜色抖动、噪声、模糊、贴真实背景，桥接 sim→real。
- **诚实定位**：只教会「图章词汇 + 遮挡语法 + 输出格式 + 坐标系」——即**读懂徽章**；
  它**不教**「真实照片→语义抽象」，那是阶段 1/2 的事。
- **Gate**：held-out 合成徽章上程序重建的 IoU / 参数误差达标（证明编码-解码闭环通了）。

### 阶段 1 · 数据引擎（专家 = 改进的经典搜索）
- **前提**：先实现一个够好的经典搜索器当专家（候选形态：贪心 + 资产替换/重启、GA/CMA-ES 进化 + 模拟退火、或二者混合）——
  必须支持**资产替换/重启**、采用**感知+显著性加权**损失、核心评估全部向量化（无逐像素 Python 循环）。它是本阶段的「数据工厂」，其质量决定 BC 上限。
- **语料**：emoji / 图标 / logo / 动漫头像 / 剪影 / 游戏贴图等**「长得像徽章」**的图，几十万级。
- **流程**：图 → 平面化（LAB k-means + 区域分割）→ 专家搜索 → `(图, 程序序列)` 对；低分样本进难例池。
- **规模/算力**：单样本搜索按秒到十秒级估，几十万物料是数十到数百 GPU·时——这是全管线最贵的一环，质量直接决定 BC 上限。

### 阶段 2 · 行为克隆 / 蒸馏
- 在 `(图, 专家程序)` 上 teacher-forcing：离散头交叉熵 + 连续头 NLL/回归。
- **DAgger**：用模型自己 rollout，让专家对模型实际访问到的状态纠偏，治 exposure bias / 误差累积。
- **Gate**：held-out 真实图上，BC 达到专家质量的 ~80–90%（**上限=专家**，诚实标注）。

### 阶段 3 · GRPO 强化学习微调（真正的 C）
- **为什么 GRPO**（调研 §四.2 提的 PPO/GRPO 中选 GRPO）：变长程序 + 稀疏终局奖励 + 没有现成 critic。
  GRPO 对同一目标采样 **G 条 rollout**，用组内相对优势当 baseline，**省掉 value net**，更稳更省。
- **流程**：对每张目标图采 G 条程序，各渲染得终局奖励 `R_i`；优势 `A_i = (R_i − mean(R)) / std(R)`；
  策略梯度最大化 `Σ_t A_i · log π(a_t | s_t)`。
- **奖励**（§5.2 详解）：CLIP + LPIPS + DINO + 结构项 − 复杂度/预算惩罚。
- **稠密 shaping**：`r_t += β·(S_{t-1} − S_t)`（相似度增量），`β` 退火到 0，缓解稀疏（§5.3）。
- **课程**：颜色数 → 预算 → 图像难度递增。
- **测试期搜索（调研 §四.2.2，详见 §5.6）**：模型提议 + 搜索裁决/refine，构成 **expert iteration**——既提质，又把更优解反哺阶段 1 的数据池，形成数据飞轮。

## 5. 核心算法细节

### 5.1 GRPO 更新（伪代码）
```
for batch of 目标图 x:
    rollouts = [ sample_program(πθ, x, budget=40) for _ in range(G) ]   # 组内 G 条
    R = [ reward(x, render(r)) for r in rollouts ]                        # 终局感知奖励
    A = (R − mean(R)) / (std(R) + ε)                                      # 组内相对优势
    loss = − mean_over_rollouts_steps( A[i] · log πθ(a_t | s_t) ) \
           + β_kl · KL(πθ ‖ π_ref)                                        # KL 防跑偏
    θ ← θ − lr · ∇loss
```

### 5.2 奖励函数与反 reward-hacking
```
R = w1·cos(CLIP(x), CLIP(canvas))            # 语义神似
  + w2·(1 − LPIPS(x, canvas))                # 感知相似
  + w3·cos(DINO(x), DINO(canvas))            # 结构/主体
  + w4·EdgeScore(x, canvas)                  # 边缘召回 / Chamfer
  − w5·(已用层数 / 40)                        # 复杂度 / 预算压力
  − penalty(超预算 | 空操作 | 全遮挡层)
```
- **反 hacking**：多指标加权避免单点作弊；**留出若干人评/未见指标不进奖励**；
  训练期定期人评 A/B 抽查，监控「奖励升但人评降」的过拟合信号（即「loss 降但不像」失效模式的复发形式）。

### 5.3 离散资产选择的取舍
- **RL 天然处理离散**：asset 当头采样 + 策略梯度，无需可微松弛，无 Gumbel 偏差。
- 若做**蒸馏/预训练**的连续参数回传，可对 pose/color 用 straight-through；asset 始终走采样。
- 这是对「全可微 + 软 argmax」路线的根本修正——离散选择不被软化。

### 5.4 分层规划（调研 §四.2）
- **宏观 Planner**：先预测区域分割 + 各区域预算配额（可借 SAM 冷启动，后期学进网络）。
- **微观 Actor**：在配额约束下放置具体图章。
- 初期可用「编码器 global token → 配额分布」的轻量头近似，不必先上完整层级。

### 5.5 图层剥离的诚实定位
- 剥离/逆合成（§五.1）在**阶段 0** 作为自监督课程价值最大（免费、无歧义）。
- 对真实照片，「补全底层 inpainting」本身是个未解子问题——不要指望它在阶段 0 之外单独扛起真实图。

### 5.6 测试期搜索（调研 §四.2.2）

- **best-of-K**：对同一目标采样 K 条完整程序，用奖励函数（§5.2）裁决取优——便宜，默认形态。
- **MCTS 前瞻**：在关键步（如前若干层的基底决策）向前模拟 3~5 步放置，以模拟终局的潜在收益回传选步，
  专治自回归的「无前瞻」短视；算力贵，按图难度动态启用。
- **裁决口径**：所有候选一律经 PIL 渲染 + §5.2 奖励打分，与交付口径一致。
- **expert iteration**：搜索发现的更优解回灌阶段 1 数据池 → 再蒸馏 → 再搜索，形成数据飞轮。

## 6. 评测

- **数据**：held-out 真实图集（不参与任何训练/搜索调参）。
- **口径**：一律用 **PIL 渲染器**渲染输出再评分（与交付口径一致）。
- **指标**：
  - 感知：LPIPS / CLIP-cos / DINO-cos。
  - 结构：边缘 p95 Chamfer / 召回率、区域拓扑一致性。
  - 层效：相似度 ÷ 层数（同等质量用更少层者胜）。
  - 人评：A/B 盲测胜率；人机协作场景的「改后续写」连贯性（§3.5）。
- **基线**：经典搜索（阶段1专家）、进化算法（GA/CMA-ES）、Geometrize 式连续图元、随机策略。
- **消融**：无预算 token / 无剥离预训练 / 无 RL（仅 BC）/ 无感知项（纯像素）——逐项验证每个设计的贡献。

## 7. 里程碑与风险

### 7.1 里程碑（gate 驱动）

| 里程碑 | 内容 | 通过门档 | 量级估算 |
|--------|------|----------|-----------|
| **M0** | 实现可微环境（§2）+ 阶段0 预训练 | 合成徽章程序重建 IoU/参数误差达标 | 1–2 周，单卡可承受 |
| **M1** | 专家搜索 + 数据引擎 + 阶段2 BC | held-out 真实图 BC ≥ 专家 ~85% | 最贵：数据引擎数十~数百 GPU·时 |
| **M2** | 阶段3 GRPO 微调 | RL > BC > 搜索基线（held-out + 人评） | RL 吞吐受限于渲染 rollout |
| **M3** | 预算感知 / 宏观规划 / 测试期搜索 | **低预算（≤20 层）下**相对基线显著优势 | 迭代式 |

### 7.2 风险登记册

| 风险 | 影响 | 缓解 |
|------|------|------|
| 专家数据天花板 | BC/RL 上限被搜索质量锁死 | 测试期搜索反哺数据（expert iteration）；难例池专项 |
| Reward hacking | 奖励升、人评降 | 多指标 + 留出指标 + 定期人评（§5.2） |
| RL 不稳 / 不收敛 | M2 卡壳 | KL 约束、稠密 shaping 退火、先小预算课程 |
| 分布漂移（语料≠用户图） | 真实图效果差 | 语料多样化 + 域随机化 + 真实难例回流 |
| 离散-连续混合训练难 | 动作头互相干扰 | 离散走采样、连续 straight-through；必要时分头课程 |
| 算力不足 | 周期拉长 | 编码器冻结、参数 ~50M、预算 token 课程缩短 RL |
| 可微环境实现质量 | 训练口径偏 | 与 PIL 版做逐层数值对齐测试（§2） |

---

## 8. 与现有代码的关系

- **PIL 渲染器**（`render.py`/`raster.py`/`stamps.py`/`models.py`）：最终导出与离线评测的唯一仲裁口径，**不动**。
- **可微环境**：独立新模块（§2），与 PIL 版做逐层数值对齐测试；不侵入渲染器代码。
- **模型/训练代码**：新建 `learn/` 子包（编码器、解码器、记忆库、GRPO、数据引擎），与 `bf_emblem_creator/` 渲染层解耦。
- 徽章 JSON 格式（`models.py`）即模型的输出 schema——动作头参数到 `StampLayer` 字段是确定映射。

---

## 9. 一页纸结论

这件事的本质是：**在 ≤40 层离散异形图章预算下，学一个「图像→几何语义抽象」的降维映射**。
难点不在网络，而在**没有现成数据**——所以真正的设计是那条**四阶段数据/训练飞轮**：
自监督预训练读懂徽章 → 经典搜索当数据工厂 → BC 蒸馏进网络 → GRPO 闭环超越专家。
网络架构（冻结编码器 + 图章记忆库 + 预算条件自回归解码器）只是承载这条飞轮的容器。
